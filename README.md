# EcoCups - Интернет-магазин бумажных стаканчиков

Веб-приложение для продажи экологичных бумажных стаканчиков с серверной частью.

## Установка и запуск

### 1. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Запустите сервер:
```bash
python server.py
```

### 3. Откройте сайт:
- Откройте `index.html` в браузере
- Или запустите локальный сервер для статических файлов

## Тестирование подключения

1. Откройте `test-connection.html` в браузере
2. Нажмите кнопки для проверки различных функций API
3. Убедитесь, что сервер отвечает корректно

## Функциональность

- ✅ Регистрация и авторизация пользователей
- ✅ Просмотр каталога товаров
- ✅ Добавление товаров в корзину
- ✅ Управление корзиной (изменение количества, удаление)
- ✅ Оформление заказов
- ✅ Личный кабинет пользователя

## API Endpoints

- `GET /api/test/` - Проверка работы сервера
- `POST /api/register/` - Регистрация
- `POST /api/login/` - Вход
- `GET /api/user/` - Информация о пользователе
- `GET /api/products/` - Список товаров
- `GET /api/cart/` - Корзина пользователя
- `POST /api/cart/` - Добавление в корзину
- `PUT /api/cart/{id}/` - Обновление количества
- `DELETE /api/cart/{id}/` - Удаление из корзины

## Технологии

- **Backend**: Flask, SQLAlchemy, JWT
- **Frontend**: HTML, CSS, JavaScript
- **База данных**: SQLite
- **CORS**: Настроен для всех источников

## Устранение проблем

### Если сайт не видит сервер:
1. Убедитесь, что сервер запущен на порту 8000
2. Проверьте файл `test-connection.html`
3. Убедитесь, что в браузере нет блокировки CORS
4. Проверьте консоль браузера на ошибки

### Если возникают ошибки CORS:
- Сервер настроен для приема запросов с любого источника
- Проверьте, что сервер запущен и доступен по адресу `http://127.0.0.1:8000`
