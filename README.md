# Cup Supply Management System 🥤

Веб-система управления поставками бумажных стаканчиков с интуитивным интерфейсом и полной автоматизацией процесса пополнения торговых автоматов.

## 🎯 О проекте

Проект разрабатывается командой из 4 человек с использованием методологии Agile. Основная цель - создание централизованной системы для:
- Управления каталогом продуктов (различные типы стаканчиков)
- Мониторинга торговых автоматов и их местоположения
- Автоматизации процесса заказов и поставок
- Ведения детальной отчетности и аналитики

## 🚀 Технологический стек

### Backend
- **Python 3.x** - основной язык программирования
- **Django** - веб-фреймворк с Admin панелью
- **SQLite/PostgreSQL** - база данных для хранения информации

### Frontend
- **HTML5** - структура веб-страниц
- **CSS3/SCSS** - стилизация компонентов
- **JavaScript** - интерактивность интерфейса
- **Bootstrap/Tailwind CSS** - адаптивная верстка

### Инструменты разработки
- **Git/GitHub** - система контроля версий
- **Figma** - проектирование ERD и UI/UX дизайна

## 🗄️ ERD и структура базы данных

ERD диаграмма проекта разработана в Figma и включает основные сущности:
- **Products** - каталог продукции (стаканчики)
- **VendingMachines** - торговые автоматы и их характеристики
- **Orders** - заказы на пополнение
- **Suppliers** - поставщики продукции
- **Users** - пользователи системы с ролями

## 🛠️ Установка и запуск

### Предварительные требования
- Python 3.8+
- Git
- Текстовый редактор (VS Code, PyCharm)

### Клонирование и настройка

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/your-team/cup-supply-system.git
   cd cup-supply-system
   ```

2. **Создание виртуального окружения**
   ```bash
   python -m venv env
   source env/bin/activate  # Linux/Mac
   # или
   env\Scripts\activate     # Windows
   ```

3. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка базы данных**
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   python manage.py createsuperuser
   ```

5. **Загрузка тестовых данных** (опционально)
   ```bash
   python manage.py loaddata fixtures/initial_data.json
   ```

6. **Запуск сервера разработки**
   ```bash
   python manage.py runserver
   ```

Система будет доступна по адресу: `http://127.0.0.1:8000/`
